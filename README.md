# POS TECH FIAP - Turma 7DTAT

##Tech Challenge fase 3 (Big Data) 

**Descrição:**

O Challenge propões o seguinte cenário:
O Aluno foi contratado para o cargo de Expert em Data Analytics por um hospital para analisar o comportamento da população durante a pandemia da COVID-19 e 
identificar indicadores importantes para o planejamento em caso de um novo surto. A base de dados PNAD-COVID-19 do IBGE foi escolhida devido à sua confiabilidade, 
mas não será necessário utilizar todas as perguntas da pesquisa. O projeto deve incluir, no máximo, 20 perguntas e deve ser concluído em três meses.

O foco deve ser em características clínicas dos sintomas, comportamento da população durante a pandemia e características econômicas da sociedade. 
O objetivo é organizar a base de dados utilizando Banco de Dados em Nuvem, selecionar as perguntas mais relevantes, realizar uma análise dessas informações e recomendar ações 
para o hospital em caso de um novo surto de COVID-19.

**Pontos-chave:**
- Criação da base de dados a partir das informações baixadas do <ins>site do PNAD</ins>
- Escolha de <ins>20 perguntas</ins> para a análise
- A base de dados deve <ins>utilizar armazenamento em nuvem</ins>
- A análise deve levar em conta <ins>3 meses</ins> de dados coletados

**Caracterísicas buscadas:**
- sintomas clínicos
- comportamento da população
- fatores econômicos da sociedade

**Objetivo final:**
- Analise da situação da população durante a pandemia (ponto de vista de um hospital)
- Recomendar ações a serem tomadas caso um novo surto aconteça
